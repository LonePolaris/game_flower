香水工坊 · 如何分享给他人游玩
================================

方式一：单文件分享（最简单）
---------------------------
1. 把本文件夹里的「play.html」发给对方（微信/QQ/邮件等）。
2. 对方用浏览器打开 play.html 即可游玩。
   - 注意：直接双击打开是「本地文件」，进度会存在对方电脑的浏览器里，可以正常玩。
3. 若想生成一个「链接」让任何人点开就玩，可以：
   - 打开 https://pages.github.com/ 按提示建一个仓库，把 play.html 上传到仓库根目录，开启 GitHub Pages，得到网址后把链接发出去；
   - 或使用 https://tiiny.host/ 、 https://www.000webhost.com/ 等免费网页托管，上传 play.html 后获得链接。

方式二：整站发布（保留多文件版本）
---------------------------------
1. 将整个「香水工坊」文件夹上传到：
   - GitHub：建仓库后上传 index.html、data.js、game.js，在仓库设置里开启 GitHub Pages，选择 main 分支，即可得到类似 https://你的用户名.github.io/仓库名/ 的链接；
   - Netlify：打开 https://app.netlify.com/drop ，把「香水工坊」文件夹拖进去，会得到一个随机链接，可分享。
2. 把得到的链接发给朋友，对方用浏览器打开即可游玩。

说明
----
- 进度保存在每位玩家的浏览器本地（localStorage），换设备或清空浏览器数据会丢失进度，可用游戏内的「保存进度」导出备份。
- 分享链接时，确保对方使用现代浏览器（Chrome、Edge、Safari、Firefox 等）。
